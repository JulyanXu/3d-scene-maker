# 按参考资料建立空间

1. 为参考资料编号，保留原始画幅，记下拍摄方向或图纸北向。列出每份资料能确定的事实。例：平面图给房间净长、门的所在墙和离墙角偏移；照片给桌子遮住窗台的范围、光线方向、木纹颜色。
2. 选择原点、坐标方向和单位。用已知尺寸定比例，区分墙内净长与墙外总长、门洞与门扇。由透视图估计的距离需要单独标注；冲突数据先检查视角、遮挡和单位。
3. 从体块开始。以照片的画幅、消失方向、地平线和几个已知角点定位相机，记录其位置、目标和视场角。只有单张图时，另外列出背面、厚度和缺少实测的尺寸推断。仅有平面图时直接核对平面位置，陈设与外观使用独立依据。
4. 锁定参考相机，采用相同画幅并排看参考和截图。选几个可命名的点或遮挡关系，例如窗框右缘、桌面前角、门洞上沿。输出第二观察位，用它检查墙后物件、家具间距和几何穿插。精确度目标由输入的测量精度决定。
5. 局部修改前记录受影响组、关键尺寸与固定物体的位置，从同一个相机捕捉前后状态；只改相关参数，再从参考相机和侧相机复验。
