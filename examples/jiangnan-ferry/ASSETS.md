# 雨歇江南渡

以“雨后黄昏的江南渡口”为文字依据进行艺术创作。地点、建筑平面、船型比例和日落方向均为创作设定。

民居和起翘的瓦顶、石拱桥、递降台阶、两艘木船、沿岸柳树均在源码中生成。石材、木材、粉墙和渡口招牌的贴图使用本地 Canvas 绘制。河面实时反射岸景，以着色器绘制微波和摇橹造成的波纹。灯笼、船身榫框、篷顶与橹的部件均有三维几何。

使用的引擎、相机控制和镜面反射组件来自 [Three.js](https://github.com/mrdoob/three.js)，作者为 Three.js contributors，采用 MIT 许可。引擎许可随 HTML 一同保存。场景运行时没有外部素材请求。
