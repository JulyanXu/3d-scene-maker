# 机械拆解互动参考

三份 HTML 由 elvarofficial 与 whaleyxbt 的 [teardown 固定版本](https://github.com/elvarofficial/teardown/tree/a91262ac1109051e014662d42ecb0b7bc1f113b1) 构建，收录为第三方教学参考。项目、Three.js 和字体的许可保存在每份 HTML 中。上游 MIT 许可同时保存在[此目录](LICENSE)。

| 在线打开 | 建议操作 |
| --- | --- |
| [Cessna 337 起落架](https://julyanxu.github.io/3d-scene-maker/examples/teardown-study/cessna-live.html) | 点击 EXPLODED 展开，按 E 收回；选择 GEARBOX 观察局部。 |
| [V8 发动机](https://julyanxu.github.io/3d-scene-maker/examples/teardown-study/v8-live.html) | 点击 SECTION，按 5 看单缸，观察活塞和气门如何随曲轴转动。 |
| [Strandbeest 步行机构](https://julyanxu.github.io/3d-scene-maker/examples/teardown-study/strandbeest-live.html) | 点击 ISOLATE LEG 单独观察一条腿，再按 T 查看足迹。 |
